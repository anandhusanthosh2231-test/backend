# 1. PRODUCT VISION

AI Recipes is an Indian-first library of **practical, tested AI workflows**.

It is NOT simply a collection of random prompts.

The product answers:

> **“I have this problem. How can I use AI to solve it?”**

Example:

Instead of:

> “Write an email.”

we provide:

> **Turn a messy WhatsApp message into a professional email**

The product should guide the user through:

```text
PROBLEM
   ↓
RECIPE
   ↓
INPUT
   ↓
COPY
   ↓
AI TOOL
   ↓
RESULT
   ↓
REFINE
   ↓
USE
```

The primary goal is usefulness.

# 84. WHEN YOU ENCOUNTER ERRORS

Do not stop and tell me:

> “There is an error.”

Investigate it.

Identify:

* cause
* affected file
* correct fix

Apply the fix.

Run the relevant test/build again.

Continue until resolved.

Only ask me if the error requires information that cannot reasonably be determined from the project.

---

# 85. WHEN YOU HAVE DESIGN CHOICES

Use good judgment.

Do not ask me about tiny decisions such as:

* border radius
* icon choice
* spacing
* component naming

Choose a professional solution.

Ask only when a decision materially changes:

* cost
* architecture
* security
* product direction
* data ownership

Optimize for:

The MVP should feel like a real product.
